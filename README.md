# Dungeon RPG

A text-based RPG dungeon-crawler game made with C++. Explore dungeons, defeat enemies, and collect powerful abilities to face off against a formidable final boss.

---

## FEATURES 🌟
- An inventory system similar to Undertale's
- Enemy encounters with combat similar to Moonring's
- A shop to buy weapons, armors, and potions from after clearing a dungeon
- Map-based exploration in the four main dungeons
- A powerful final boss to defeat at the end of the game
- Saving and loading (COMING SOON!)

## INSTALLATION ⚙️
Clone the repository while in your desired directory:

```bash
git clone https://github.com/Program-Arcana/dungeon-rpg.git
```

Navigate to the repository directory to begin using it.


Compile the program with the following command: 

```bash
make
```

Run the program with the following command:
```bash
./rpg
```

Have fun playing the game!
